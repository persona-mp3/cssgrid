To start this projet in vscode, first install the extensino, live server from the extensions tab


After installation, click on the icon at the bottom fo the screen that says `Go Live`


And then run this in the integrated terminal


```npm i ```

That will install all the dependencies to run the project


After it is done with installing, run this


```npm run server```

That will start a server on youer terminal inside vscode where you'll be able to track all activities



To run the tests the server must be working

```cd tests``

Open a new terminal

```npm test```
